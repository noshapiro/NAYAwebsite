Как открыть сайт на своём компьютере
=====================================

1. Открой Терминал (Terminal).

2. Перейди в папку проекта:
   cd "/Users/noashapiro/Downloads/NAYA website/nearu-site"

3. Запусти сервер (один из вариантов):
   npm run dev
   Если пишет "another instance running" или не открывается — используй:
   npm run dev:fresh

4. В браузере открой (порт 3099):
   http://127.0.0.1:3099

   Pitch deck:
   http://127.0.0.1:3099/pitch

5. Если страница пустая:
   - Открой DevTools (F12 или Cmd+Option+I) → вкладка Console. Есть ли красные ошибки?
   - Попробуй другой браузер (Chrome, Safari, Firefox).
   - Убедись, что в адресе именно http:// (не https://).

6. Если пишет "port in use":
   Останови другой процесс: в Терминале нажми Ctrl+C, затем снова npm run dev.
   Или закрой другие окна Терминала, где мог запускаться этот же проект.
